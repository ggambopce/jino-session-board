# 세션 보드

세션 기록(`~/.claude/projects/**/<세션ID>.jsonl`)과 보드 파일(`~/.claude/session-board/<세션ID>.md` 또는
`~/.claude/session-plans/<세션ID>.md`)을 읽어서 현황판을 만든다. 밖으로 보내는 것은 없다.

## 고르는 기준

| 상황 | 방식 |
|---|---|
| 작업하는 동안 옆에 띄워 두고 계속 보고 싶다 (기본 추천) | 실시간 보드 (프로젝트 보드) |
| 이 세션 하나만 따로 띄우고 싶다고 분명히 말했다 | 실시간 보드 (세션 하나) |
| 지금 상태를 한 번만 본다, 파일로 남긴다 | HTML 한 장 |
| 화면을 열 수 없다, 대화창에서 글로 받고 싶다 | 텍스트 요약 |

## 실시간 보드

기본은 프로젝트 보드다. 같은 작업 폴더의 세션들을 서버 하나, 브라우저 탭 하나로 왼쪽 목록에서 골라 본다.
세션마다 서버와 탭을 따로 띄우지 않아 메모리를 덜 쓴다.

백그라운드로 실행한다 (run_in_background). 출력 첫 줄의 주소를 사용자에게 알려 준다.

```bash
node "${CLAUDE_SKILL_DIR}/scripts/board.mjs" --project --session "${CLAUDE_SESSION_ID}" --serve --open
```

- 같은 프로젝트 보드가 이미 떠 있으면 새로 띄우지 않고 그 주소를 알려 준 뒤 바로 끝난다. 그 보드를 보고 있는 탭이 있으면 탭을 새로 열지 않고 그 탭을 이 세션으로 넘긴다. 이때는 출력 둘째 줄이 「이미 떠 있는 보드입니다」로 시작하니, 같은 보드라고 알려 준다.
- 왼쪽 목록은 앱 사이드바와 같은 세션 제목, 마지막 활동, 진행판 진행률, 작업 중 표시를 보여 준다. 고른 세션은 주소 끝 `#session=<세션ID>` 에 남는다.
- 목록은 「켜져 있음」(프로세스가 살아 있음)과 「꺼짐」(꺼졌지만 앱 사이드바에 있음)으로 나뉜다. 꺼졌고 앱에도 없는 세션(닫은 VS Code 세션, 보관한 앱 세션)은 맨 아래 「닫힌 세션 N개 보기」에 접혀 있다. 닫힌 세션은 × 단추로 목록에서 빼고 「되돌리기」로 되돌릴 수 있다. 보드 목록만 바뀌고 대화 기록은 그대로다 (`~/.claude/session-board/hidden.json`).
- 목록 오른쪽 끝을 끌어 너비를 바꾸고, 아주 좁히거나 위쪽 단추로 아이콘만 남길 수 있다 (기본은 이름 앞 두 낱말의 첫 글자로 된 두 글자 아이콘, 켜짐·작업 중 점). 아이콘 글자는 두 번 누르기나 F2 로 네 글자까지 바꾸고, 길면 두 줄로 보인다 (`~/.claude/session-board/labels.json`).
- 켜져 있는 세션 옆 끄기 단추로 그 세션의 Claude 프로세스와 하위 프로세스를 끈다 (사용자가 보드에서 확인을 누를 때만). 메모리를 줄이고 싶다는 사용자에게 안내할 수 있다.
- 세션 하나만 띄우려면 `--project` 를 빼고 실행한다 (예전 방식, 세션마다 서버 하나).
- 2초마다 갱신된다. 턴이 끝나면 브라우저 알림을 보낼 수 있다 (탭 줄 오른쪽 설정 단추의 「답이 끝나면 알림」). 프로젝트 보드에서는 보고 있지 않은 세션이 끝나도 알린다. 탭 켜고 끄기, 순서, 밝은 화면도 같은 메뉴에 있다.
- 바뀐 파일과 이미지를 기본 프로그램으로 열고, 로컬 주소가 켜져 있는지 표시한다.
- 127.0.0.1 에서만 열리고 주소에 든 열쇠가 있어야 접근된다. 기본 120분 동안 접속이 없으면 스스로 꺼진다 (`--ttl <분>`).

## HTML 한 장

```bash
node "${CLAUDE_SKILL_DIR}/scripts/board.mjs" --session "${CLAUDE_SESSION_ID}" --format html --open
```

## 텍스트 요약

```bash
node "${CLAUDE_SKILL_DIR}/scripts/board.mjs" --session "${CLAUDE_SESSION_ID}" --format text
```

## 옵션

| 옵션 | 뜻 |
|---|---|
| `--session <id>` | 볼 세션. 빼면 현재 폴더의 가장 최근 세션 |
| `--transcript <경로>` | 세션 기록 파일을 직접 지정 |
| `--format html\|text\|json` | 출력 형태 (기본 html) |
| `--out <경로>` | HTML 저장 위치 (기본 임시 폴더) |
| `--open` | 만든 화면을 기본 브라우저로 연다 |
| `--window <토큰수>` | 컨텍스트 창 크기. 주면 사용률(%)도 계산. 안 주면 화면은 모델 이름으로 어림 (haiku 200K, 그 밖은 1M) |
| `--serve`, `--port <번호>`, `--ttl <분>` | 실시간 보드 |
| `--project [작업 경로]` | `--serve` 와 함께: 프로젝트 보드. 경로를 빼면 `--session` 이 든 프로젝트, 없으면 현재 폴더의 프로젝트 |

## 결과를 전할 때

- 화면을 열었으면 주소나 파일 경로를 알려 주고, 눈에 띄는 것(남은 단계, 실패한 검사, 교차검증 지적)만 한두 줄로 덧붙인다.
- text: 출력된 요약을 그대로 길게 옮기지 말고, 사용자가 물은 부분 위주로 간추린다.
- 스크립트가 세션을 못 찾으면 `--transcript` 로 경로를 직접 주어 다시 실행한다.

## 진행판 쓰기

진행판 규칙은 한 곳에서만 온다.

- side-panel 플러그인이 꺼져 있으면 이 플러그인의 훅이 세션마다 `~/.claude/session-board/<세션ID>.md` 경로와 규칙을 알려 준다.
- side-panel 플러그인(`side-panel@...`)이 사용자, 프로젝트, 로컬 설정 중 어디서든 켜져 있으면 (뒤 설정이 앞 설정을 덮는다) 이 플러그인의 훅은 아무것도 알리지 않는다.
  side-panel 이 알려 주는 `~/.claude/session-plans/<세션ID>.md` 한 곳에만 쓰면 되고, 같은 내용을 session-board 폴더에 또 쓰지 않는다.

어느 훅 안내도 없으면 `~/.claude/session-board/<세션ID>.md` 에 다음 모양으로 직접 쓴다.

```markdown
# 이번 목표를 한 줄로
- [x] 마친 단계 - 한 일
- [ ] 아직 남은 단계
```

스크립트는 두 폴더의 파일을 모두 찾아보고, 둘 다 있으면 더 최근에 고친 파일을 보여 준다.
둘 다 없을 때는 세션 기록의 할 일 목록(TodoWrite 등)을 대신 보여 준다.
